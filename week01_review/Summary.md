# Summary 🧾

Throughout this Python learning process, I have studied the fundamental concepts that form the core of programming logic and code structure. The learning began with basic input and output using _print()_ and _input()_, followed by the use of variables and an introduction to **data types** such as integers, floats, strings, and booleans. At this stage, I also learned **basic arithmetic** operations to perform numerical calculations.

Next, I explored **conditional statements** using _if_, _elif_, and _else_ to make decisions within a program. This was supported by **comparison operators** and **logical operators** _(and, or, not)_, which allowed me to build more complex conditions and strengthen logical thinking.

I then learned **looping structures**, including _for_ and _while_ loops, to execute repetitive tasks efficiently. The use of _break_ and _continue_ helped control loop execution based on specific conditions.

In addition, I studied **Python data structures**, namely **lists, tuples, sets, and dictionaries**, which are essential for storing, organizing, and managing data in different formats, including ordered collections, immutable data, unique values, and key–value pairs.

Finally, I learned how to create and use functions, covering basic function definitions, parameters, and return values. This enabled me to write more modular, reusable, and well-structured code.

Overall, these topics provided a strong foundation in Python programming and prepared me for developing more advanced and structured applications.
